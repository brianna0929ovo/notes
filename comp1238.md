
# COMP1238 Midterm Notes

## Week 1 - Introduction to Computing
- Computers use binary numbers (0 and 1) to represent data.
- One byte contains 8 bits.
- RAM is volatile memory, meaning data is lost when the power is turned off.

## Week 2 - Text and Character Encoding
- ASCII is a character encoding standard used to represent text.
- UTF-8 supports many languages and special characters.
- Plain text editors are different from word processors like Microsoft Word.

## Week 3 - Markdown and GitHub
- Markdown uses # for headings and - for bullet lists.
- GitHub repositories store files and track changes.
- A commit saves changes to a repository.

## Week 4 - Text Editing and Searching
- Ctrl + F is used to search for text in a document.
- Case-sensitive searches distinguish uppercase and lowercase letters.
- Regular expressions help find text patterns.

## Week 5 - Command Line Basics
- CLI stands for Command Line Interface.
- The `ls` command lists files and directories.
- The `cat` command displays the contents of a file.
- Command-line tools are useful for automation and working with remote servers.
